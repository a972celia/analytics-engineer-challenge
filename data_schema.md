# Sources

1. ae_ad_network_1_campaign_updates.csv - Campaign history report from Ad Network 1

| Field name                  | Description                  |
| --------------------------- | ---------------------------- |
| campaign_id                 | ID of a marketing campaign from Ad Network 1      |
| update_date                 | Date when the campaign info was updated        |
| name                        | Name of the campaign        |


2. ae_ad_network_1_geo_dictionary.csv - Geo dictionary for Ad Network 1

| Field name                  | Description                  |
| --------------------------- | ---------------------------- |
| id                          | ID of a location             |
| country_code                | Alpha‑2 code of a country    |
| name                        | Full name of the location    |
| location_type               | Type of the location         |


3. ae_ad_network_1_country_report.csv - Country-level performance report of Ad Network 1

| Field name                  | Description                  |
| --------------------------- | ---------------------------- |
| date                        | Date                         |
| campaign_id                 | ID of a marketing campaign from Ad Network 1    |
| country_id                  | ID of a location (country)   |
| spend                       | Ad spend                     |
| impressions                 | # Impressions of the ads     |
| clicks                      | # Clicks on the ads          |


4. ae_ad_network_1_detailed_report.csv - State-level performance report of Ad Network 1 when applicable

| Field name                  | Description                  |
| --------------------------- | ---------------------------- |
| date                        | Date                         |
| campaign_id                 | ID of a marketing campaign from Ad Network 1    |
| country_id                  | ID of a location (country)   |
| state_id                    | ID of a location (state)     |
| spend                       | Ad spend                     |
| impressions                 | # Impressions of the ads     |
| clicks                      | # Clicks on the ads          |


5. ae_ad_network_2_report.csv - Performance report of Ad Network 2

| Field name                  | Description                  |
| --------------------------- | ---------------------------- |
| id                          | ID of a marketing campaign from Ad Network 2      |
| campaign_name               | Name of a marketing campaign from Ad Network 2    |
| date                        | Date                         |
| spend                       | Ad spend                     |
| impressions                 | # Impressions of the ads     |
| clicks                      | # Clicks on the ads          |
